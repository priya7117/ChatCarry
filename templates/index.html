ChatCarry

Carry a project from one AI chat to the next without losing what matters.

For accurate extraction, use speaker-labelled turns such as You: and Claude:, or import the original conversations.json. ChatCarry accepts .txt/.md and JSON exports, not DOCX. Pasted text without speaker labels is kept as unknown instead of guessing.

Settings

Sent to this app's server for this request only. It is not saved or logged. To avoid pasting it every time, put it in a .env file (see the README).

Privacy

Emails, phone numbers, passwords, API keys and tokens are replaced with placeholders on the server before the text is split or sent anywhere. This is pattern matching, so skim your chat for anything unusual.

Options

Click "Save project" and it appears under "My projects" on the first page. Next time, choose "Add a new chat" there and the new chat is merged into it, so the project stays up to date. The downloaded .json file works the same way if you want a backup.
